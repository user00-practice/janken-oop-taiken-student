# STEP2 GUI・OOP版（クラスに分けて作る）

ボタンで遊ぶじゃんけんを、役割ごとにクラスを分けて作ります。画面（`MainFrame`）はできあがっているので、じゃんけんの中身を担当するクラスの TODO を書きます。

## クラスの役割

| クラス | 役割 | 覚えていること・できること |
| --- | --- | --- |
| `Hand` | じゃんけんの手（グー・チョキ・パー） | 表示名、ほかの手に勝つかどうか（`beats`） |
| `Player` | 参加者1人 | 名前、今出している手、勝った回数 |
| `CpuPlayer` | コンピュータの参加者（`Player` を受け継ぐ） | Player の機能に加えて、手を自分で決める（`decideHand`） |
| `JankenGame` | じゃんけんの進行役 | 参加者に手を出させ、勝った人を決める（`play`） |
| `MainFrame` | 画面 | ボタンを表示し、押されたら JankenGame を呼ぶ（**完成済み**） |

## 実行方法

実行構成「STEP2 GUI・OOP版」を選んで▶を押します。TODO を書く前でも起動はできます（CPU の手が「？」のまま、いつも「あいこ」になります）。

## やること

| TODO | ファイル | やること | ヒント |
| --- | --- | --- | --- |
| TODO A | `Hand.java` | `beats`：この手が相手の手に勝つなら true を返す | switch式で、この手（this）ごとに分ける |
| TODO B | `CpuPlayer.java` | `decideHand`：手をランダムに決める | `Hand.values()` で3つの手の配列が手に入る |
| TODO C | `JankenGame.java` | `play`：勝敗を判定して、勝った人を返す | TODO A で作った `beats` を使う |

## できたら確認

- [ ] ボタンを押すと、CPU の手が毎回変わる
- [ ] 勝ち・負け・あいこが正しく表示される
- [ ] あなたと CPU の勝った回数が、それぞれ正しく増える

## 考えてみよう

STEP1 の「勝った回数」は main メソッドの変数でした。STEP2 では、勝った回数をだれが覚えているでしょう。
