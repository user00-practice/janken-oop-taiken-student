# STEP1 CUI版（制御構造で作る）

コンソールで遊ぶじゃんけんを、クラスを分けずに **main メソッドの中だけ** で作ります。手は数字で表します（0：グー、1：チョキ、2：パー）。

## 実行方法

実行構成「STEP1 CUI版」を選んで▶を押します。画面下のコンソールに数字を入力して Enter を押すと、じゃんけんができます。9 で終了します。
